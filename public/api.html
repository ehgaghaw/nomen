Register (wallet-signed)

Registration needs no transaction and no fee. The owner proves control of a wallet by signing a plain-text message with ed25519 (what every Solana wallet's signMessage does).

POST/api/nonce { wallet }
POST/api/message { action, name, wallet, nonce } → { message }
POST/api/register { name, tokenName, ticker, description, image, mintKind, mint, links, wallet, nonce, signature }
POST/api/update { name, description, links, image, wallet, nonce, signature }
POST/api/transfer { name, to, wallet, nonce, signature }

The signature is the 64-byte detached ed25519 signature of the message bytes, base64 encoded. The message format is:

Nomen — register milo.mint

Wallet: <base58 wallet address>
Nonce: <nonce from /api/nonce>

No transaction. No fees. This signature only proves wallet ownership.

Rules

Names are 3–24 characters: lowercase letters, numbers and single hyphens, no hyphen at either end. Short and generic names such as ai.mint or sol.mint are reserved. Name, ticker and token address are immutable; everything else is editable by the owner. One wallet can hold up to 100 names. Names identify tokens inside Nomen, not the public DNS.
